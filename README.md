## Overview

Production pipeline for processing real-time audio streams into actionable business intelligence. Handles live speech-to-text transcription, real-time sentiment analysis, emotion detection, and automated extraction of sales signals and insights.

Built at **Reallytics.ai** as part of the voice AI platform, supporting sales teams, call centers, and customer service operations.

## Key Features

- **Real-Time Transcription**: Live speech-to-text using Whisper and AWS Transcribe with < 2s latency
- **Streaming Sentiment**: Continuous sentiment and emotion tracking throughout conversations
- **Speaker Diarization**: Identify and separate multiple speakers in conversations
- **Sales Intelligence**: Automatic detection of buying signals, objections, and next steps
- **Entity Extraction**: Real-time extraction of names, companies, products, dates, and amounts
- **Conversation Analytics**: Talk-to-listen ratio, interruption patterns, topic flow analysis
- **Alert System**: Real-time notifications for critical conversation events
- **Historical Analysis**: Aggregated insights across conversations for trend analysis

## Tech Stack

| Category | Technologies |
|---|---|
| **Speech-to-Text** | Whisper, AWS Transcribe |
| **NLP** | spaCy, HuggingFace Transformers, NLTK |
| **Sentiment** | Custom fine-tuned BERT, TextBlob |
| **Streaming** | Apache Kafka, WebSockets |
| **Compute** | Python, NumPy, librosa |
| **Cloud** | AWS (Lambda, S3, Transcribe, SQS) |
| **Database** | PostgreSQL, Redis, TimescaleDB |
| **API** | FastAPI, Server-Sent Events |
| **Monitoring** | Grafana, Prometheus |
